KRK Story is a control panel for a Minecraft community. Admins create server instances on demand, and players get the mods, resource packs, and shaders for each server through a custom launcher.

## Why

I built KRK Story so admins could manage modded servers from a browser and players could get the right files for each server through the launcher.

## What I built

- **Server management.** Create, start, stop, restart, and remove server instances from the browser. Docker images support Minecraft 1.12.2, 1.20.1, and 1.21.1.
- **File manager.** Browse server files and edit configuration files in the browser.
- **Launcher packs.** Open a pack from a link. The launcher reads its file list and downloads missing or changed files.
- **Role-based access.** Control who can view community pages and manage servers.

## Technical challenges

**Limiting Docker access.** Separate Express services manage files and server instances. The Next.js app checks access before forwarding requests to those services, which hold the Docker socket.

**Allocating ports.** New instances take the first free port in a configured range. The service saves the mapping so it can find running servers after a restart.

**Verifying downloaded files.** The pack manifest lists a SHA-256 hash for each file. The launcher compares those hashes and replaces files that have changed or become corrupted.
