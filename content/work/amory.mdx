Amory is a storefront where players buy in-game items and services. Staff manage the store through a separate admin app.

## Why

I built Amory to give players a checkout tied to their game account and give staff one place to confirm payments and reconcile orders.

## What I built

- **Storefront and admin app.** The two Next.js apps share a NestJS API, and all three deploy separately from one repository.
- **Payment gateway.** Players can pay with LINE Pay or TrueMoney Wallet. Gateway callbacks confirm payments automatically.
- **Transaction reconciliation.** Staff can match gateway records against orders in the admin app.
- **Player accounts.** Store accounts link to the game's player database and support two-factor authentication.

## Technical challenges

**Connecting two databases.** PostgreSQL holds storefront data, and the game server's MySQL database holds player accounts. The NestJS API is the sole service that connects to both.

**Testing payment callbacks locally.** The gateway sends callbacks to a public HTTPS URL. Tailscale Funnel exposes the local storefront, which forwards callbacks to the local API for testing.

**Preserving uploads during deployment.** Amory runs on Coolify with Docker Compose. Uploaded media lives on a persistent volume, and the project documents how to migrate existing files there.
