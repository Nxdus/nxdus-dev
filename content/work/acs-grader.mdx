ACS Grader is the contest platform used for ACS First Meet, a programming event run by the Applied Computer Science program at KMUTT. Contestants write and submit code in the browser. The platform grades submissions automatically and posts scores to a live leaderboard.

## Why

The event needed a contest platform that the program could run itself, with control over the problems, schedule, and grading setup.

## What I built

- **Contests and a problem archive.** Each contest problem defines the allowed languages, maximum score, and hidden test cases.
- **Browser-based code editor.** Write code in Monaco and run it against sample cases before submitting.
- **Sandboxed grading.** Judge0 runs submissions in isolation and returns a result for each test case.
- **Contest scheduling and leaderboard.** Contests open and close on schedule. Contestants can follow scores on the live leaderboard.
- **Admin dashboard.** Manage contests, problems, and users, and review individual submissions.
- **Sign-in.** Better Auth supports Google, GitHub, and verified email addresses.

## Technical challenges

**Partial scoring.** Each contest problem awards a share of its maximum score based on the fraction of test cases passed. The grader rounds the result down to a whole point.

**Drafting test cases.** Organizers can generate and review draft test cases before publishing. If the first model fails, the app tries a fallback model through OpenRouter.

**Packaging releases.** GitHub Actions builds and publishes a standalone Docker image for deployment.
