Lomra is a desktop canvas for images, video, and 3D models. Add references, edit a frame, and generate variations without leaving the canvas.

## Why

I wanted a single workspace for reference files and AI tools. Lomra stores project files on your device. Supported local models can run offline after setup, and hosted models receive the inputs needed for each request.

## What I built

- **Infinite canvas.** Organize briefs, references, and outputs, capture video frames, and inspect GLB models.
- **Image editor.** Annotate images with arrows, shapes, and text, remove backgrounds, and paint masks to guide AI edits or extend an image beyond its borders.
- **Storyboards.** Group references by shot, generate one clip per shot, and join the clips with FFmpeg.
- **Hosted and local AI tools.** Use OpenRouter, fal.ai, or Google AI Studio, or enable local models for chat and tools (Ollama), images (stable-diffusion.cpp), 3D (Hunyuan3D and TripoSR), and transcription (Whisper).

## Technical challenges

**Running a web app on the desktop.** Electron starts a Next.js server that serves the interface. A sandboxed preload bridge connects the renderer to the main process. API keys are encrypted on disk, and Electron's `safeStorage` protects the encryption key when available.

**Running local models offline.** Users enable local runtimes as needed. Lomra checks model downloads against SHA-256 hashes and enables Hugging Face's offline mode for the 3D worker.

**Testing and releasing the desktop app.** The Electron app and the frontend each have a test suite run with `bun test`. CI builds the Windows installer from release tags.
